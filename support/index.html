Your first connection

Add a connection: enter the server address, data path, request method and sign-in details. Create a template and choose the data for your report. Ask the specialist responsible for your API if you need help.

401 or 403 errors

Check credentials and access rights with the API owner. App support does not ask for your passwords or tokens.

No report data

Check the period, parameters, JSON array path and server availability. An empty array, an incorrect path and a network error are different situations.

Working offline

The demo works offline. Your own reports may use matching previously downloaded data; the first download requires a connection.

Loading data and filters

MetricNote can load data in pages. Loading options and available filters depend on your API.

Sharing a template

Share a template using the system share sheet. It contains report settings but excludes saved authentication credentials. Check names and paths before sharing: they may contain information you entered.

Exporting and deleting data

CSV contains table rows; PNG contains the chart. Deleting a connection removes its credentials, templates and cache. Shared files and backups must be removed separately.
