Политика конфиденциальности MetricNote

Обновлено: 24 октября 2026 года.

MetricNote строит отчёты по JSON-данным из API, которые настраивает пользователь. Приложение не содержит рекламы, сторонней аналитики и средств отслеживания. Разработчик не получает содержимое ваших отчётов или данные авторизации через приложение.

Хранение на устройстве

Подключения, шаблоны, избранное, параметры отчётов и кэш ответов сохраняются локально. Адреса API, токены, API-ключи, логины и пароли хранятся в Keychain с доступом только на разблокированном устройстве и без переноса на другие устройства. Обычные данные приложения могут входить в резервную копию устройства согласно настройкам iOS.

Приложение использует локальные настройки для онбординга и избранного. Время создания временных файлов используется только для удаления экспортов старше суток при следующем экспорте.

Сетевые запросы

При проверке подключения и загрузке отчёта запросы отправляются на настроенный вами сервер. Он получает параметры запроса, данные авторизации и сетевую информацию, необходимую для соединения, включая IP-адрес. Обработка данных этим сервером регулируется правилами его владельца. Используйте доверенные API и HTTPS.

При перенаправлении на другой HTTPS-адрес приложение запрашивает ваше подтверждение. После подтверждения другому серверу могут передаваться данные запроса и авторизации; доверие сохраняется для этого подключения в Keychain.

Демонстрационный отчёт работает без сети.

Импорт и передача файлов

Импортированные шаблоны обрабатываются локально; размер выбранного файла проверяется для ограничения объёма импорта. Экспорт CSV и PNG содержит данные отчёта. При отправке шаблона исключаются сохранённые данные авторизации, пользовательские заголовки и значения параметров URL; проверьте имена и пути перед передачей. Файлы передаются другим приложениям только по вашему действию через системное меню iOS. Дальнейшее хранение определяется выбранным приложением или получателем.

Удаление данных

Удаление подключения удаляет его авторизацию, связанные шаблоны и кэш приложения. Ранее отправленные файлы и резервные копии необходимо удалять отдельно средствами соответствующего приложения или iOS. Данные авторизации в Keychain могут сохраняться после удаления приложения; для их удаления сначала удалите подключения внутри MetricNote.
