METRICNOTE · PRIVACY

MetricNote Privacy Policy

Updated: 24 October 2026.

MetricNote creates reports from JSON APIs configured by the user. The app contains no advertising, third-party analytics or tracking tools. The developer does not receive your report contents or API authentication credentials through the app.

Storage on your device

Connections, templates, favorites, report parameters and cached responses are stored locally. API addresses, tokens, API keys, usernames and passwords are stored in Keychain, accessible only while the device is unlocked and without transfer to other devices. Ordinary app data may be included in device backups according to your iOS settings.

Local preferences store onboarding state and favorites. Creation dates of temporary export files are used only to remove exports older than one day when another export is created.

Network requests

Connection checks and report downloads send requests to the server you configure. That server receives request parameters, authentication information and network information needed for the connection, including your IP address. The server owner's policies govern its processing of that data. Use trusted APIs and HTTPS.

When redirected to a different HTTPS address, the app asks for your approval. After approval, request and authentication data may be sent to the other server; trust is saved in Keychain for that connection.

The demonstration report works without a network connection.

Importing and sharing files

Imported templates are processed locally; the size of the selected file is checked to limit the import size. CSV and PNG exports contain report data. Shared templates exclude saved authentication credentials, custom headers and URL query parameter values. Check names and URL paths before sharing them: those fields may still contain information you entered.

Files are shared with other apps only when you choose to use the iOS share sheet. The selected app or recipient determines subsequent storage.

Deleting data

Deleting a connection removes its credentials, related templates and app cache. Previously shared files and backups must be deleted separately using the relevant app or iOS settings. Keychain credentials may remain after uninstalling the app; delete connections inside the app first if you want to remove those credentials.

Questions

For questions about app data, contact lagutoff45@gmail.com. The app copyright owner is Viacheslav Lagutov. Questions about a configured API's data processing should be directed to that API's owner.

This website

This website uses no analytics, advertising, data collection forms or external fonts. When hosted on GitHub Pages, visitor IP addresses are stored by the host for security. If you contact support by email, the message contents and sender address are transmitted to your email service and the recipient.
