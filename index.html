Before your first report

Will it work with my API?

MetricNote works with compatible JSON APIs. You need the server address and access to the data. Available filters and loading options depend on your API.

Do I need to write code?

You can configure reports in the app without writing code. Connecting may require information about your API or help from a specialist.

Can I share a template with a colleague?

Yes. The file includes connection settings, fields and chart preferences. Saved credentials, custom headers and URL parameter values are excluded. Check names and paths before sharing.
